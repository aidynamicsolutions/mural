## Boundary review, before editing

The coordinator has one local audio owner and a shared serialized local tutor. Local Talk is English learning with Vietnamese support, not a Vietnamese-learning module. `localPairSupported`, `startLocal`, the local MeaningController closure, and `scheduleTranslation` hard-code Vietnamese. `prepareConversation` selects PhoWhisper. Meaning cache keys already include the requested meaning language. `LocalTutorModel` separately defines conversational reply, meaning/word lookup, and last-passage assessment instructions. Help currently produces spoken easier English. The audio owner retains an ASR actor for a conversation and drops it at existing Stop boundaries. Breeze already transcribes entire recordings; it does not need a word router or transcript conversion.

The existing receipt policy is retained. It includes manifest, path, OS build, device, actual compute units, scope and manually versioned policy. Writes follow successful normal load and validation, using atomic replacement. Cancellation is checked around native calls and immediately before commit. A cancellation after that final check can race an already-completed successful atomic commit; a receipt records successful preparation, not continued model ownership. Trials bypass production receipts. The staged receipt covers only the decoder. It never vouches for the Core AI encoder cache.

### Local review note: rejected relocation-stable receipt experiment

Physical verification found a development reinstall could preserve the app database, assets and receipt while changing the data-container identity. An initial experiment changed the receipt from an absolute model-path hash to a storage-root-relative path and bumped the policy version. Unit tests and the Release build passed. On the exact same executable after another in-place install, the revised receipt correctly reported a hit and skipped explicit prewarm, but the authoritative normal Core ML load still took 177.693 seconds before cancellation. An immediate retry loaded and reached Ready in 4.628 seconds. This shows a receipt hit does not guarantee fast native loading; it is consistent with renewed native preparation, but does not establish Apple's internal cache key or reinstall as the sole cause. Treating the relocated path as reusable did not eliminate the measured cost, so the experiment was reverted. The absolute path remains in the receipt as the conservative native-cache identity. Development installs may therefore require one new preparation; fresh-process reuse without another install remains fast. Evidence is under `.build/verification/taiwan-talk/20260922-113707/receipt-relocation-*-key-events.log`. An online reviewer should consider this result before proposing stable paths or weakening the normal load.

## Focused implementation

1. Add a stable, explicit local speech-pair selection. Default missing legacy metadata to Vietnamese–English; persist the selected pair on every new session and use it when restoring. Keep English as the learning language. Never derive the pair from words, automatic locale detection, or recognizer output.
2. Select Breeze once for a Taiwan Mandarin–English conversation. Keep its PAL8 model, transcription options, tokenizer, VAD and receipt behavior. Replace the argument pin with the supplied fixed digest and exact revision. Keep raw recognition in an optional provenance field independent of display text and generated support.
3. Parameterize the existing tutor/meaning boundary. English conversational practice and existing English TTS remain English. Taiwan meanings, lookup and explicit Help use Traditional Chinese with Taiwan usage; Help is on-screen support, not Mandarin sent to the English TTS voice. Keep this content in the existing translation cache, not in learner recognition. Do not claim prompt instructions prove language quality. Keep new-pair automatic learning assessment disabled pending separate semantic qualification; preserve Vietnamese assessment.
4. Add a small selected-package provisioning path: a reviewed catalog, canonical pinned manifest, bounded resumable HTTP ranges, chunk/file verification, same-volume immutable package publication, and an atomic active pointer. Preserve old valid packages until an explicit storage action. Packages contain model data, not executable application code. Do not bundle weights or automatically fetch a second mode.
5. For normal staged Talk, check/create the encoder specialization and validate its ABI before readiness. Use the same `AIModel.specialize(contentsOf:options:cachePolicy:)` API already used in the repository harness, keep GPU preference and the pinned FP8/PAL8 pair, and drain native work after cancellation. Validate the decoder on preparation rather than first declaring readiness without it. Explicit qualification trials retain their existing scheduling.
6. Use existing Talk controls plus a speech-model sheet for download offer, sizes, progress, cancellation, retry and managed storage. Missing distribution is a visible release blocker, never a fake successful download or model fallback.

A. Receipt regression: same/fresh process reuse, no skipped verification/loading, cancellation and unchanged trial policy.
B. Taiwan Talk: actual English/Mandarin/mixed transcripts, Traditional Chinese meanings/Help/lookup, no silent normalization, one model, lifecycle, persistence and accessibility.
